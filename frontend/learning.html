Comprehensive technical specifications, pin diagrams, and operating principles for popular microcontrollers and IoT sensor modules.

Arduino UNO

Beginner-friendly microcontroller board based on the ATmega328P. Widely used for prototyping robotics and embedded electronics due to its simplicity and rich ecosystem.

Pins: 5V, 3.3V, GND, A0-A5, D0-D13 (6 PWM)
Microcontroller Wiki Docs →

ESP8266 (NodeMCU)

Low-cost Wi-Fi microcontroller with a built-in TCP/IP stack. Enables direct cloud connectivity, IoT home automation, HTTP servers, and MQTT telemetry.

Pins: D0-D8, 3V3, GND, VIN, A0 (Analog)
WiFi MCU Wiki Docs →

Ultrasonic Sensor (HC-SR04)

Measures distance using high-frequency 40kHz sound waves. Calculates time-of-flight for the acoustic echo pulse. Ideal for obstacle detection and liquid level sensing.

Pins: VCC (5V), Trig, Echo, GND
Acoustic Range Wiki Docs →

PIR Motion Sensor (HC-SR501)

Detects human movement by sensing changes in infrared radiation emitted by warm objects. Features dual potentiometers for sensitivity and delay time adjustment.

Pins: VCC, Digital OUT, GND
Infrared Motion Wiki Docs →

Gas Sensor (MQ-2)

Detects flammable gas concentrations including LPG, propane, methane, hydrogen, and smoke. Contains internal heating element and variable resistance sensor.

Pins: VCC, GND, A0 (Analog), D0 (Threshold)
Gas / Safety Wiki Docs →

Soil Moisture Sensor

Measures volumetric water content in soil by determining dielectric permittivity or resistive conductivity between dual probes. Vital for smart agriculture.

Pins: VCC, GND, A0, D0
Agriculture Wiki Docs →

DHT11 Temp & Humidity

Calibrated digital temperature and relative humidity sensor. Uses a single-wire custom protocol to communicate digital telemetry packets reliably.

Pins: VCC, Data (Pull-up), NC, GND
Environmental Wiki Docs →

RC522 RFID Reader

13.56 MHz contactless reader module using SPI communication. Reads Mifare RFID cards, fobs, and tokens for attendance and electronic lock systems.

Interface: SPI (SDA, SCK, MOSI, MISO, RST)
Access Control Wiki Docs →

LDR Photoresistor

Cadmium-sulfide (CdS) photo conductive cell whose electrical resistance decreases as ambient light intensity increases. Paired with a voltage divider circuit.

Output: Analog Voltage (with 10k resistor)
Optical Wiki Docs →
