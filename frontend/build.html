Obstacle Avoidance Robot

Components: Arduino Uno, HC-SR04 Ultrasonic Sensor, L298N Motor Driver, 2x DC Motors, 9V Battery

Autonomous 2WD rover that senses frontal obstacles with sonar waves and turns towards the clearest path.

Wiring Checklist:

  • Ultrasonic VCC → 5V, GND → GND
  • TRIG → Pin 9, ECHO → Pin 10
  • Motor Driver IN1-IN4 → Pins 4, 5, 6, 7
  • Motors connected to Driver OUT1-OUT4

Smart Irrigation System

Components: Arduino Uno, Soil Moisture Sensor, 5V Relay Module, Mini Submersible Pump, 12V DC Adapter

Automated plant watering system that energizes the pump relay only when soil moisture drops below calibrated threshold.

Wiring Checklist:

  • Soil Sensor VCC → 5V, GND → GND
  • Sensor Analog OUT → Pin A0
  • Relay Signal IN → Pin 7
  • Water pump wired through Relay COM & NO

Smart Door Lock System

Components: Arduino Uno / ESP32, RC522 RFID Module, SG90 Servo Motor, Buzzer, LED Indicators

Keyless security system unlocking the physical door latch servo upon authentication of valid RFID tags.

Wiring Checklist:

  • RC522 SPI → SDA(10), SCK(13), MOSI(11), MISO(12)
  • Servo Signal → Pin 9, VCC → 5V, GND → GND
  • Buzzer → Pin 8, Status LED → Pin 7
  • Configure Authorized Card UIDs in Code

Fire Detection System

Components: Arduino Uno, IR Flame Sensor Module, Active Buzzer, Red Warning LED, 5V Relay

Wiring Checklist:

  • Flame Sensor VCC → 5V, GND → GND
